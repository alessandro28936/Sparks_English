Update 12 November - Faster Daily Import v2: Membaca dan mengurutkan tanggal terdampak saja. Target 2 menit, durasi tiap tahap tercatat. Pasang versi ini setelah proses lama selesai.

  1. Klik Copy script di bawah. Yang disalin adalah kode Apps Script, bukan HTML halaman ini.
  2. Di Centers, buka Extensions → Apps Script.
  3. Buka Code.gs yang berisi Sparks Import. Ganti seluruh isinya dengan script yang disalin. Jika sebelumnya Anda memasangnya di file bernama SparksImport, ganti file tersebut. Jangan membuat salinan fungsi yang sama.
  4. Klik Save. Untuk pembaruan ini tidak perlu Deploy atau menjalankan setup lagi.
  5. Tutup dialog upload lama, refresh Google Sheet, lalu buka Sparks Import → Upload Daily Report CSV. Pilih file harian, gunakan Update ad / dates in file, klik Preview, lalu Import.

Importer busy berarti file baru belum diimpor. Tunggu tombol Import tersedia. Import completed mengonfirmasi proses dengan Import ID yang sama. Tombol Check status tidak menulis ulang data.
